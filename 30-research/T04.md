# T04 — MakeCode block/API technical reference

Merged union of 3 lanes, no adjudication. Grounds REFINE's technical-accuracy critique. Applies to L1-s1..s6 (all).

## hermes

- `forever` runs its contained code repeatedly as a background task, starts automatically at launch, takes no parameters. — https://makecode.microbit.org/reference/loops/forever
- `show string` scrolls text left across the 5x5 matrix; required text string + optional interval (ms between characters, default 150ms). — https://makecode.microbit.org/reference/basic/show-string
- `show icon` displays one icon from IconNames until the next display command; one icon-name parameter. — https://makecode.microbit.org/reference/basic/show-icon
- `pause` suspends the current fiber for ms but does not block other parallel forever loops or event handlers. — https://makecode.microbit.org/reference/basic/pause
- `if/then/else` evaluates a boolean, runs then when true / else when false; both branches optional in the editor. — https://makecode.microbit.org/reference/logic/if
- `on shake` registers via `input.onGesture(Gesture.Shake, handler)`. — https://makecode.microbit.org/reference/input/on-gesture
- `pick random` (`Math.randomRange`) returns a random integer between two inclusive bounds. — https://makecode.microbit.org/reference/math/random
- `input.acceleration(Dimension)` returns acceleration along X/Y/Z in milli-g. — https://makecode.microbit.org/reference/input/acceleration

## codex

- `forever` repeatedly runs its body in the background and yields to other code — should NOT be described as preventing event handlers from running. — https://makecode.microbit.org/reference/basic/forever
- `show string` scrolls left when text exceeds the display; optional interval is ms per one-LED slide, larger = slower. — L1-s1,s3 — https://makecode.microbit.org/reference/basic/show-string
- `show icon` optional interval is display time in ms, default 600ms. — L1-s2,s3,s6 — https://makecode.microbit.org/reference/basic/show-icon
- `pause` takes ms; 500ms = half second, 1000ms = one second. — L1-s2 — https://makecode.microbit.org/reference/basic/pause
- `if/then/else`: then branch on true, else branch on false, outcomes specified separately. — L1-s5,s6 — https://makecode.microbit.org/lessons/blocks-conditions
- `on shake` = `input.onGesture(Gesture.Shake, handler)`; other gesture choices include orientation, tilt, free-fall, 3g, 6g. — L1-s4,s6 — https://makecode.microbit.org/reference/input/on-gesture
- `pick random` maps to `randint(min, max)`, inclusive both endpoints. — L1-s6 — https://makecode.microbit.org/reference/math/randint
- `input.acceleration(dimension)` in milli-g for x/y/z/strength; flat screen-up ≈ x=0,y=0,z=-1023,strength=1023. — L1-s4 — https://makecode.microbit.org/reference/input/acceleration

## opencode

- `forever` is event-based, yields to other code; no `break`/`continue` inside it (unlike for/while). — L1-s1,s2 — https://makecode.microbit.org/reference/basic/forever
- `show string` optional interval (ms) controls scroll speed. — L1-s1,s3 — https://makecode.microbit.org/reference/basic/show-string
- `show icon` optional interval default 600ms. — L1-s1,s4 — https://makecode.microbit.org/reference/basic/show-icon
- `pause(ms)`: 1000ms = 1s; if ms is NaN, defaults to 20ms. — L1-s2,s4 — https://makecode.microbit.org/reference/basic/pause
- `if` runs inner code only when condition true; else/else-if added via `+`; conditional not sequential. — L1-s3,s5 — https://makecode.microbit.org/blocks/logic/if
- `on gesture` (`input.onGesture`) parameter includes shake, logo up/down, screen up/down, tilt left/right, free-fall, 3g, 6g. — L1-s5,s6 — https://makecode.microbit.org/reference/input/on-gesture
- `pick random` inclusive both bounds; `Math.randomRange` deprecated in favour of `randint`. — L1-s6 — https://makecode.microbit.org/reference/math/random-range
- `input.acceleration(dimension)` in milli-g; dimensions X/Y/Z/Strength; flat screen-up: x=0,y=0,z=-1023,strength=1023. — L1-s6 — https://makecode.microbit.org/reference/input/acceleration
