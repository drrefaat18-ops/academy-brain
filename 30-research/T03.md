## codex

- A worked answer should name the required event/startup context, ordered blocks inside it, and expected LED/output behaviour, so cosmetic variations can still be judged correct. — L1-s1,s2,s4,s5,s6 — MID:observable-behavior-and-structure
- Name badge: canonical is `show string` with the learner's name in `on start`; flag blank/incorrect text, unattached block, or wrong handler. — L1-s1 — https://mbit.io/tutorial-name-badge
- Beating heart: canonical is a repeating two-frame heart animation with pauses between frames; accept the course's 500ms pause, flag static single-frame, missing pauses, or blocks outside the loop. — L1-s2 — https://microbit.org/projects/make-it-code-it/beating-heart/
- Emotion badge: canonical uses an input event selecting/displaying the emotion icon; flag always-same output, wrong button/gesture handler, or ungrouped image block. — L1-s4 — MID:event-output-match
- Step counter: canonical initializes `steps` to a known value, increments on shake, displays count; flag omitted init, wrong variable/increment, stale display. — L1-s4 — https://microbit.org/teach/lessons/step-counter/
- Nightlight: canonical continuously tests light level, shows image when dark, clears otherwise; flag reversed comparison, missing else-clear, or leftover shake/`steps` logic. — L1-s5 — MID:nightlight-canonical-code
- Rock-paper-scissors: canonical responds to shake with one of three random outcomes and matching image; flag fixed/non-random outcome, missing shake handler, incomplete three-way mapping. — L1-s6 — https://microbit.org/teach/lessons/rock-paper-scissors/

## opencode

- Name badge: canonical is `on start` running `showString` once — event-driven single-run, NOT a forever loop (would re-scroll constantly). — L1-s1 — MID:makecode-onstart-vs-forever
- Beating heart: canonical is a forever loop alternating two heart icons with pause blocks; placing animation in `on start` is a key mistake (runs once, no beating). — L1-s2 — MID:makecode-animation-pacing
- Beating heart: answer keys must require pause blocks (~500ms) between frames; omitting pauses flickers too fast to read as "beating." — L1-s2 — MID:makecode-pause-required
- Emotion badge: canonical uses on-button/on-gesture event handlers each showing one icon; flag forever-loop polling with if/else as non-canonical. — L1-s4 — MID:makecode-event-handlers
- Step counter: canonical initializes counter to 0 on start, increments on shake, shows on button A; flag missing init (NaN/junk) and button-press-instead-of-shake. — L1-s5 — MID:makecode-variable-init
- Nightlight: canonical is forever + if comparing light level BELOW threshold; flag reversed comparison (>) or equality (=) instead of threshold. — L1-s6 — MID:makecode-threshold-comparison
- Across all tasks: canonical structure is event-driven blocks + forever only where repetition is needed; flag non-canonical control flow (showString inside forever, missing clear/reset). — L1-s1,s2,s4,s5,s6 — MID:makecode-control-flow
