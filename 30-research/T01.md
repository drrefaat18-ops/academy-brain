# T01 — Differentiation strategies for micro:bit kids-track intro unit

Merged union of 3 lanes (hermes, codex, opencode), no adjudication — REFINE stage judges. Applies to L1-s1..s6 (all).

## hermes

- For struggling learners, retain a step-by-step tutorial and an animated-GIF build alternative so the core program can be followed through more than one guided representation. — L1-s2 — https://microbit.org/projects/make-it-code-it/beating-heart/
- For advanced learners, reserve an explicit Extend phase after the core create-and-evaluate sequence, allowing a short lesson to offer stretch without making it a prerequisite for success. — L1-s3 — https://mbit.io/tutorial-emotion-badge
- Use the canonical lesson's extension-by-ability guidance to keep a common core task while offering optional challenges for learners who finish quickly. — L1-s4 — https://microbit.org/teach/lessons/step-counter/
- Provide support and challenge as separate options around the same light-sensing if/then program, rather than replacing the introductory task for either group. — L1-s5 — https://microbit.org/teach/lessons/
- Pair support with stretch in the rock-paper-scissors lesson so all learners can complete the shake-and-random core while faster learners extend it. — L1-s6 — https://microbit.org/teach/lessons/rock-paper-scissors/
- Use a Think-Create-Evaluate-Extend-Share lesson arc with teacher notes and a recap so learners needing help receive repeated context while advanced learners have a defined point for independent extension. — L1-s1..s6 — https://microbit.org/projects/make-it-code-it/beating-heart/

## codex

- micro:bit's published lesson plans embed paired "support" and "stretch" differentiation notes in each short lesson, so a single 45-60 minute session can scaffold struggling learners and extend advanced ones without a second plan. — L1-s1..s6 — https://microbit.org/teach/lessons/step-counter/
- For primary-aged (8-11) learners who struggle, micro:bit lessons rely on teacher-led scaffolding plus a step-by-step tutorial or a pre-built "remix" project so they still reach the core forever-loop + show-string/icon outcome. — L1-s1,s2,s3 — https://microbit.org/teach/lessons/
- micro:bit lessons give advanced learners an "Extend" phase with open-ended challenges (change pause timing, add a second animation, combine inputs) instead of capping the task. — L1-s2,s3,s5,s6 — https://microbit.org/projects/make-it-code-it/beating-heart/
- Within an if/then + shake + random lesson, stretch is delivered by remixing the core program while the support tier keeps a single-branch if/then skeleton. — L1-s5,s6 — https://microbit.org/teach/lessons/rock-paper-scissors/
- CS-education guidance for primary block coding favours "low floor, high ceiling" single-lesson tasks. — L1-s1..s6 — MID:principle-low-floor-high-ceiling
- The Techno Square repackaging of these lessons dropped the upstream support/stretch differentiation (with assessment and answer key), a gap the kids-track intro unit must restore. — L1-s1..s6 — https://microbit.org/teach/lessons/

## opencode

- Adopt a "low floor, high ceiling" design: basic activity all students can complete, then optional extension challenges for early finishers. — L1-s1..s6 — https://microbit.org/news/2024-09-26/3-classroom-management-strategies-for-teaching-with-microbit/
- Share pre-written starter code via micro:bit Classroom so struggling learners aren't faced with a blank screen. — L1-s1..s6 — https://www.bbc.co.uk/teach/microbit/articles/zpsxywx
- Use mixed-ability pairs/small groups (1 device : 2-3 learners), pair programming (driver/navigator). — L1-s1..s6 — https://microbit.org/news/2025-08-04/practical-tips-for-successful-microbit-lessons/
- For conceptual struggles, ask the pupil to explain the code line by line to find bugs; model metacognitive troubleshooting aloud if they can't. — L1-s1..s6 — https://microbit.org/news/2025-08-04/practical-tips-for-successful-microbit-lessons/
- Use tiered "Mild / Medium / Spicy" learning objectives within a single lesson. — L1-s1..s6 — https://microbit.org/teach/lessons/interactive-math-practice-with-activity-picker/
- Red/yellow/green cup progress indicators let the teacher prioritise pupils who are completely stuck. — L1-s1..s6 — https://microbit.org/news/2024-09-26/3-classroom-management-strategies-for-teaching-with-microbit/
- For learners who find shake/button presses hard, swap the input event for touch-logo, sound, or an external switch. — L1-s3,s4 — https://microbit.org/accessibility/fine-motor-and-mobility/
- Stretch advanced learners by letting them create their own challenge from the same block set rather than stopping at the modelled task. — L1-s4,s5,s6 — https://microbit.org/news/2024-09-26/3-classroom-management-strategies-for-teaching-with-microbit/
