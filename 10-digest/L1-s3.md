# L1-s3

## Slide 1: Lesson 3Emotion badge

## Slide 2: Recap: what did we discover about animations?

Last time we used sequences of instructions code animations on the micro:bit’s LED display output.
We used the ‘forever’ loop block to keep the animation running.
The micro:bit’s display, even though it only has 25 LEDs, can show pictures that represent real things like hearts or animals.

## Slide 3: Think:     sharing feelings

Today we’re going to make badges that show how we feel.

What emotions might we want to express?

Why could this be useful?

**Speaker notes:**

Some people find it hard to express or read emotions and a badge like this can be helpful for them.

## Slide 4: Think:     learning objectives

I can make the micro:bit show different pictures on the LED display output depending on which button input is pressed.

I can explain that inputs are data sent to a computer.

I can explain that outputs are data sent from a computer.

**Speaker notes:**

Ask your students what other inputs and outputs they can think of.
Keys on a keyboard, a touch screen or buttons on a game controller are inputs.
The display on a phone or game console, or sound from a phone or game console speakers are examples of outputs.

## Slide 7: Create:    examine the code

The ‘on button A pressed’ block makes something happen when you press input button A.
The ‘show icon’ block makes an image appear on the LED display output. You can choose different built-in images.
The ‘on button B pressed’ block makes something happen when you press input button B.
So you can make different outputs happen on the LED display when you press different button inputs.

## Slide 13: Extend

Add more icons when you press A + B input buttons together.
Design your own emotion images on paper. Code them using the ‘show LEDs’ block.
Can you make another emotion appear if you shake your micro:bit?

**Speaker notes:**

You can use the LED grid planning sheet download or any paper to draw new emotion images.
To add a shake input, use the ‘on shake’ block in the Input section of MakeCode.

## Slide 14: Share:     revisit the learning objectives

I can make the micro:bit show different pictures on the LED display output depending on which button input is pressed.

I can explain that inputs are data sent to a computer

I can explain that outputs are data sent from a computer.

**Speaker notes:**

Ask students:
How did they make their micro:bits show different images? (Using different buttons and the ‘on button pressed’ input code blocks)
What are inputs? (Data sent to a computer for processing such as button presses and sensor readings. Examples of inputs include the buttons on a game controller or the touch screen on a phone).
What are outputs? (Data sent from a computer such as information shown on a display. Other examples of outputs include phone or game screens or sound from speakers)
