# Language Rule

**Source Label:** Designer-Provided

## Summary
All educational output follows a fixed 30% English / 70% Arabic split, with the Arabic held to strict style constraints. ^language-rule-split

## The Split
- **English (30%):** titles, coding terms, technical terminology, STEM/robotics vocabulary, block/tool names
- **Arabic (70%):** explanations, instructions, trainer guidance, student/parent engagement, concept clarification

## Arabic Style Constraints
Must be: simple, clear, age-appropriate, beginner-friendly, short, easy to read, visually correct, RTL-friendly.
Avoid: heavy academic Arabic, long paragraphs, complex theory, adult-level explanations for young learners.

## Example Style
> Push يعني أزق الحاجة بعيد.
> Pull يعني أسحب الحاجة ناحيتي.
> Icon Block بيقول للـ Robot يعمل إيه.

## Why This Matters for Understanding Moon OS
Language mixing isn't incidental style — it's a fixed ratio with an enforced register (simple Arabic, precise English technical terms). This is part of what makes output age-appropriate across 5 very different tracks (see [[78_Academy_Track_Roadmap]]).
