# AI Tools Workflow Guide

## NotebookLM

Use NotebookLM for:

- Student Slides
- Student Home Summary
- visual robotics explanation
- visual STEM presentation

NotebookLM works best when sources are focused.

Do not overload NotebookLM with too many files.

For Student Slides, use:

- lesson material
- trainer guide
- educational decision note
- branding rules
- Tata guide
- key robot/project images
- key code screenshots

For Home Summary, use:

- trainer guide
- final slides
- educational decision note
- branding rules
- key project images

Avoid:

- unrelated previous sessions
- too many raw screenshots
- trainer-only overload

## Gemini / Nano Banana

Use Gemini / Nano Banana for:

- worksheets
- trainer guide visual PDFs
- visual educational layouts

Worksheet rule:

Less assets = better results.

Use:

- one worksheet style reference
- logo
- one Tata mascot
- main project images only
- one block/code reference if needed

Trainer Guide visual rule:

Upload:

- trainer guide draft PDF
- trainer guide template
- logo
- optional Tata
- optional project images

## Canva

Canva is optional.

Use Canva for:

- small manual edits
- fixing Arabic text if AI image output breaks it
- polishing templates
