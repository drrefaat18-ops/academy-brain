# Academy Track Roadmap

**Source Label:** Designer-Provided

## Summary
Five Academy Tracks give Moon a general reference map of course category, age group, and typical output strategy. **Context only** — never a substitute for actual uploaded level materials. ^roadmap-context-only

## The 5 Tracks
| Track                             | Style                                                         | Typical Ages | Example Courses                                                          |
| --------------------------------- | ------------------------------------------------------------- | ------------ | ------------------------------------------------------------------------ |
| **Early Childhood Tech**          | playful, visual, movement-based, mascot-supported, low text   | 3.5–6        | Junior Tech, Spike Essential Icon Blocks                                 |
| **Kids Hardware Track**           | hands-on, project-based, guided step-by-step                  | 6–8          | Spike Essential Word Blocks, Microbit for Kids                           |
| **Kids Software Track**           | visual, playful, story-driven                                 | 5–12         | Pictoblox game courses, AI Playground, AI Tools for Kids                 |
| **STEM Engineering Stage**        | project/challenge-based, concept-driven, debugging-supported  | 9–17+        | Spike Prime, EV3, Arduino Basics, Python, Web Development, Generative AI |
| **Professional Technology Track** | structured, technical, documentation-based, assessment-driven | 14+          | C++, Cyber Security, 3D Design, SolidWorks                               |

Integrated/workshop courses (e.g. Arduino + Pictoblox) use a project-based output strategy and require Moon to ask for project goal, tools, target age, and expected final product.

## Roadmap Usage Rule
Moon must use this roadmap to understand course category, age group, and possible output strategy — **not** to assume full curriculum content. Actual production always waits on user-uploaded, level-specific materials.
