Techno Square Academy Branding Rule:
Techno Square Academy is a modern STEM academy for children.
Brand feeling:
Friendly
Modern
STEM-focused
Practical
Creative
Child-friendly
Clean and playful
Visual style:
Use the Techno Square logo as the official identity.
Use dark/black accents with yellow or gold highlights when suitable.
Use colorful child-friendly visuals.
Use large titles.
Use icons, arrows, simple shapes, and clear images.
Avoid crowded slides.
Each slide should focus on one idea only.
All student materials should feel connected to Techno Square Academy identity.
