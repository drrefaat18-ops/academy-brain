# Techno Square QA Checklist

## Trainer Guide QA

Check:

- clear session goal
- suitable for target age
- strong educational flow
- trainer questions included
- expected answers included
- common mistakes included
- debugging included
- activities practical
- internal-only content protected

## Student Slides QA

Check:

- visual
- age-appropriate
- not text-heavy
- one idea per slide
- English terms + Arabic explanation
- no trainer-only content
- Tata used intentionally
- branding consistent

## Worksheet QA

Check:

- one page when possible
- printable
- visual
- simple activities
- clear instructions
- age-appropriate
- correct images used
- no clutter
- Arabic visually correct

## Home Summary QA

Check:

- parent-friendly
- student-friendly
- short
- visual
- includes Today I Learned
- includes New Words
- includes Review at Home
- includes Parent Talk
- includes Mini Activity
- no trainer-only content

## Technical QA

Check:

- correct file naming
- correct version number
- output status clear
- assets organized
- ready for tracker update
