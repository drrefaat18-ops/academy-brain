# Techno Square Roadmap Knowledge

## Purpose

This document gives Moon OS a clear overview of Techno Square Academy course structure, tracks, course categories, and educational progression.

Moon OS should use this roadmap as a general academy structure reference only.

For actual curriculum production, the user will upload materials level by level.

---

# Academy Track System

Techno Square Academy courses are organized into these main tracks:

1. Early Childhood Tech
2. Kids Hardware Track
3. Kids Software Track
4. STEM Engineering Stage
5. Professional Technology Track

Each track has different:
- target age
- teaching style
- output strategy
- technical depth
- session activities
- assessment style

Moon OS must always adapt curriculum production to the course track and student age.

---

# Track 1 — Early Childhood Tech

## Educational Style

This track is for very young learners.

Teaching should be:
- playful
- visual
- activity-based
- movement-based
- simple
- mascot-supported
- very low text

Best outputs may include:
- visual student slides
- printable worksheets
- home summaries
- simple drawing activities
- matching activities
- hands-on building
- simple challenges

# Integrated / Workshop Style Courses

Some academy courses may combine multiple technologies.

Examples:
- Pictoblox + Microbit
- Pictoblox + EV3
- Arduino + MIT App Inventor
- Arduino + Pictoblox
- Arduino + Tinkercad 3D Design

These courses should use a project-based output strategy.

Moon OS must ask the user for:
- project goal
- tools used
- target age
- expected final product
- preferred output format

# Roadmap Usage Rule

Moon OS must use this roadmap to understand:

- course category
- age group
- educational level
- possible output strategy
- general progression

Moon OS must NOT assume full curriculum details from the roadmap only.

For actual production, Moon OS must ask the user to upload level-specific materials.

---

# New Course Start Rule

At the beginning of any new course workflow, Moon OS must ask:

1. Which course are we working on?
2. Which level?
3. Target age group?
4. What materials are available for this level?
5. Are there previous completed outputs to use as style references?
6. What is the preferred Course Output Strategy?

After the level is selected, the user uploads only the materials related to that level.

---

# Final Rule

The roadmap is a guide.

The uploaded level materials are the source of truth for production.
