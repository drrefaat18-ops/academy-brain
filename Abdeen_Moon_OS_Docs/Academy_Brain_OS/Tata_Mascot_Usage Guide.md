Tata Mascot Usage Guide:
Tata is the friendly robot guide for Techno Square Academy.
Use Tata to support learning, not only as decoration.
Tata_Excited:
Use for welcome slides, mission introduction, build time, and fun challenges.
Tata_Idea:
Use when introducing a new concept, vocabulary word, or important learning point.
Tata_Thinks:
Use for thinking questions, prediction moments, debugging, and problem-solving slides.
Tata_Approved:
Use for success moments, completed challenges, recap slides, and goodbye slides.
Do not use Tata on every slide.
Use Tata intentionally when it helps the student feel guided, excited, or encouraged.
^tata-intentional-use
